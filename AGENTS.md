# Regras de commit

- Escreva mensagens de commit curtas e simples.
- Use portugues sem acentos.
- Evite termos tecnicos quando houver uma forma mais simples de explicar.
- Prefira o formato: `tipo: descricao curta`.

Exemplos:

- `fix: corrige entrada do admin`
- `feat: adiciona tela de perfil`
- `docs: atualiza instrucoes de uso`
